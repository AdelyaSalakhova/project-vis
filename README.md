# Онлайн-тренировки

Интерактивный исследовательский дашборд учебного проекта по визуализации данных.

Откройте `index.html` в браузере. Данные встроены в HTML: отдельный датасет, сервер и установка библиотек не нужны.

Дашборд показывает динамику просмотров, оценок и глубины просмотра, позволяет сравнивать тренеров и типы тренировок, выбирать недели и группы активности пользователей. Нажатие на столбик тренировки открывает отдельные просмотры.

Карточки показателей закреплены при прокрутке. Два блока мини-графиков показывают последние 10 недель программы.

Источник данных: «Онлайн-тренировки, 10 недель (1).xlsx».
